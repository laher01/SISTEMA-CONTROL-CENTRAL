---

# PROCESO PRINCIPAL DEL NEGOCIO

FACT CENTRAL administra expedientes digitales de compras empresariales.

El objetivo del sistema es recibir documentación de compras, organizarla automáticamente, relacionar todos sus documentos, generar un expediente digital inteligente y proporcionar información estratégica para la toma de decisiones.

# REGLAS

1. Todo proceso deberá pertenecer a un macroproceso.

2. Todo documento generado deberá formar parte de un expediente.

3. Ningún documento permanecerá aislado.

4. Todo expediente tendrá un ciclo de vida.

5. Toda acción quedará registrada para auditoría.

6. Toda modificación deberá conservar el historial.
