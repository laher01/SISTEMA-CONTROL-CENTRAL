# docs/futuro

Documentación de **visión a largo plazo** que queda fuera del alcance del MVP.

Se conserva íntegra, pero no bloquea el desarrollo actual. Cada documento se
retomará cuando el MVP ([`docs/MVP.md`](../MVP.md)) esté en producción con
clientes reales y exista una necesidad concreta que lo justifique.

| Carpeta | Contenido |
|---|---|
| `nexus/` | NEXUS (capa de IA), motores cognitivos (memoria, razonamiento, decisión, estrategia, aprendizaje…), agentes, misiones, gemelo digital e inteligencia estratégica. |
| `infraestructura/` | Topología multi-nodo, disaster recovery multi-región, capacity planning, modelo de costos, salud del sistema y centro de operaciones autónomo. |

Regla: nada de esta carpeta se implementa antes de terminar y validar el MVP.
