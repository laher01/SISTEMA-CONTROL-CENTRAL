# Incorporación obligatoria

FACT CENTRAL es SaaS multi-tenant, no ERP independiente. Inspeccionar `main`, registros, PR, Issues y ramas antes de actuar. Si otro chat desarrolla una funcionalidad, coordinar y no duplicar. Trabajar por rama y PR. INTEGRADO, DESPLEGADO y VERIFICADO requieren pruebas distintas. Tenant se valida en backend, no desde el cliente.
