# Leer primero — incorporación a FACT CENTRAL

1. Consultar `main` actualizado y arquitectura real, sin suponer funcionalidades.
2. Consultar PR abiertos, ramas, Issues y este directorio.
3. Leer responsables en `02_RESPONSABLES_ETAPAS.md` y tareas en `03_TRABAJOS_EN_CURSO.md`.
4. Confirmar que no exista duplicación funcional o conflicto de archivos.
5. Declarar archivos a modificar, pruebas y dependencias antes de desarrollar.
6. Trabajar en rama aislada y PR; no fusionar ni desplegar sin autorización.
7. Registrar evidencia de resultados y actualizar estado cuando corresponda.

Estados: PROPUESTO → ASIGNADO → EN DESARROLLO → EN PRUEBAS → PR ABIERTO → INTEGRADO → DESPLEGADO → VERIFICADO. BLOQUEADO y CANCELADO cuando aplique. Las últimas tres etapas no son equivalentes.

**Importante:** este Centro es una propuesta de coordinación; no concede por sí mismo permisos ni reemplaza la verificación del repositorio vivo.
