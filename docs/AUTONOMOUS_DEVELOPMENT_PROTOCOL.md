# FACT CENTRAL

# AUTONOMOUS DEVELOPMENT PROTOCOL

Versión: 1.0

Estado: Oficial

Última actualización: Agosto 2026

---

# PROPÓSITO

Definir el protocolo oficial de desarrollo autónomo de FACT CENTRAL.

Este documento establece cómo interactúan ChatGPT, Codex, GitHub, GitHub Copilot y Visual Studio Code para construir el sistema manteniendo la visión, arquitectura y reglas del proyecto.

---

# OBJETIVO

Automatizar al máximo el proceso de documentación, diseño, implementación y pruebas sin perder el control arquitectónico.

La documentación será la fuente oficial de verdad.

Toda implementación deberá respetar la documentación aprobada.

---

# PRINCIPIO FUNDAMENTAL

En FACT CENTRAL:

La documentación dirige el desarrollo.

La arquitectura dirige la documentación.

La visión del negocio dirige la arquitectura.

La IA implementa.

Nunca al revés.

---

# HERRAMIENTAS OFICIALES

## ChatGPT

Responsabilidades

- Diseñar arquitectura.
- Crear documentación.
- Mantener coherencia.
- Crear reglas de negocio.
- Diseñar plataformas.
- Diseñar motores.
- Diseñar modelos de datos.
- Diseñar APIs.
- Diseñar contratos.
- Auditar documentación.
- Proponer mejoras.

No implementa directamente en producción.

---

## Codex

Responsabilidades

- Leer documentación oficial.
- Generar Backend.
- Generar Frontend.
- Generar Base de Datos.
- Generar Tests.
- Generar Docker.
- Generar Scripts.
- Refactorizar código.

Nunca modifica la arquitectura.

---

## GitHub

Responsabilidades

Repositorio oficial.

Control de versiones.

Pull Requests.

Historial.

Versionado.

---

## GitHub Copilot

Responsabilidades

Asistencia local.

Autocompletado.

Refactorización.

Ayuda al desarrollador.

No toma decisiones arquitectónicas.

---

## Visual Studio Code

Centro de desarrollo.

Edición.

Depuración.

Pruebas.

Integración Git.

# APROBACIÓN AUTOMÁTICA

Se autoriza automáticamente:

- Crear documentación.
- Crear diagramas.
- Crear contratos.
- Crear modelos.
- Crear APIs.
- Crear estructuras.
- Crear código nuevo.
- Crear pruebas.
- Crear migraciones.

Siempre respetando la documentación oficial.

---

# APROBACIÓN MANUAL

Siempre requerirá aprobación:

- Cambiar reglas de negocio.
- Cambiar arquitectura.
- Cambiar permisos.
- Cambiar seguridad.
- Cambiar modelos de datos.
- Eliminar módulos.
- Eliminar motores.
- Eliminar plataformas.

---

# OBJETIVO FINAL

Construir un sistema donde la mayor parte del desarrollo pueda ser ejecutada automáticamente por agentes de IA respetando siempre la arquitectura, la visión del negocio y las reglas oficiales del proyecto.

# VISIÓN FUTURA

FACT CENTRAL evolucionará hacia una plataforma donde:

- La documentación sea la fuente de verdad.
