# DEFINICIÓN

El Smart Expedient (Expediente Inteligente) es la unidad principal de información dentro de FACT CENTRAL.

No representa únicamente un conjunto de documentos.

Representa una compra empresarial completa, organizada, relacionada, validada y enriquecida automáticamente mediante inteligencia artificial.

Cada expediente constituye un gemelo digital (Digital Twin) de una operación comercial.

---

# OBJETIVO

Centralizar toda la información correspondiente a una compra empresarial dentro de una única entidad inteligente.

El expediente será la fuente oficial para consultas, auditorías, reportes e inteligencia de negocios.

# PRINCIPIOS

Un expediente representa una operación empresarial.

Nunca un documento aislado.

Toda la documentación relacionada deberá integrarse dentro del mismo expediente.

El expediente constituye el Digital Twin oficial de la operación.

Toda consulta deberá realizarse sobre el expediente y no sobre documentos individuales.
