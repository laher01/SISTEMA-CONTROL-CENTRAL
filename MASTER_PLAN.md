# FACT CENTRAL

ERP Inteligente de Gestión Documental, Expedientes e Inteligencia de Negocios.

---

## Estado del Proyecto

**Versión:** 1.0 (Arquitectura)

**Estado:** Diseño y planificación

**Infraestructura objetivo**

- Frontend: Cloudflare Pages
- Backend: FastAPI
- Base de datos: PostgreSQL
- IA: OpenAI API
- Almacenamiento: VPS + Cloudflare
- Control de versiones: GitHub

---

## Filosofía del Proyecto

Antes de escribir una sola línea de código:

1. Diseñar.
2. Documentar.
3. Validar.
4. Programar.
5. Probar.
6. Publicar.

Toda nueva funcionalidad deberá quedar documentada antes de ser desarrollada.
