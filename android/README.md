# FACT CENTRAL Android — prototipo técnico 0.1
Cliente nativo Java, conexión HTTPS a app.nexomarnegocioseirl.online y sesión temporal en memoria. No incluye credenciales, acceso SQL, ni almacenamiento persistente de comprobantes. Roles y permisos de Secretaría se consultan en servidor; SUPERADMIN únicamente muestra información de cuenta. La API sigue siendo la autoridad final.

La API del dominio configurado devolvió HTTP 401 sin sesión en `/api/v1/auth/me` y HTTP 200 en `/api/v1/auth/administracion-publica` según comprobación de la VPS. Falta una prueba autenticada desde Android. No cambiar la URL sin verificar tenant, autenticación y certificados.\n\nAlcance inicial: revisión agregada SUNAT de solo lectura, consulta de alertas, inicio de sesión, cierre de sesión, resumen, listas de documentos y expedientes según rol, navegación móvil. Pendientes: escáner/cámara, cargas, detalle, descargas, notificaciones push, compatibilidad visual completa y prueba autenticada en dispositivo. No es una versión de producción.

Compilar: JDK 17, Android SDK 35, Gradle 8.9; `gradle -p android testDebugUnitTest lintDebug assembleDebug`. El workflow del PR no despliega ni utiliza secretos. El APK de depuración está destinado a pruebas; la firma de producción requiere configuración independiente.
